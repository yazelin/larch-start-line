# 《起跑總在開始前》設計規格

日期：2026-10-05
用途：Larch 第三屆創作者挑戰《自由與限制》投稿作品
截稿：2026-10-24（評審週 10/25–10/31 仍可修 bug，以截稿前最後一版計分）

## 1. 目標與限制

- 作品長度 8～10 分鐘，使用 RPG 擴充功能（地圖探索、事件、道具、任務提示）。
- 劇情以 `canon/原文.md` 為準，原文不改字。新寫的文字（結局 B、備用鑰匙說明、轉盤選項、路人台詞）放 `canon/新寫.md`，由作者定稿。
- 不打怪：所有地圖 `combat:"none"`。
- 美術全部自製，不用 Kenney 素材；畫風統一為柔和水彩插畫。
- 每一條路徑都要能走到結局，不能因為走錯而卡死（挑戰規則）。

## 2. 主題怎麼對上「自由與限制」

| 挑戰頁的鎖 | 在作品裡的位置 | 玩家實際碰到的事 |
|---|---|---|
| 看得見的束縛 | 第一輪，起跑前兩秒 | 一動就是偷跑，裁判吹哨重來；同時心裡想什麼由玩家自選 |
| 看不見的束縛 | 第二輪前半 | 林向晚不能被他發現、不能太刻意：要躲在看台後、要先打聽他的習慣 |
| 心裡的束縛 | 第二輪結尾的分支 | 販賣機前沒有任何東西擋她，只剩自己決定讓零錢掉下去或轉身 |

作品的回答：跑道上有人替你開槍，愛情沒有。自由是沒有人替你喊開始，所以槍得自己扣。結局 B 是這句話的反面（完全自由，卻從未起跑）。結局 A 的備用鑰匙是另一面：自己選來交給別人的限制。

## 3. 遊戲流程

```
序章（文字卡）
 └ 第一輪：程徹（田徑場地圖，round=1）
    └ 中章（文字卡）
       └ 第二輪：林向晚（同一張田徑場地圖，round=2）
          ├ 讓零錢掉下去 → 防波堤後半（文字卡）→ 結局 A：台北廚房（小地圖）
          └ 轉身離開   → 結局 B（文字卡）→ 可回到販賣機前重選
```

### 序章（文字卡）
原文第 1–2 段（「在槍響之前……」「所謂的起跑……」）。

### 第一輪：程徹，高二市運會選拔賽
1. 任務提示「去檢錄處拿號碼布」。拿到道具「號碼布」「別針」。
2. 經過終點線後方觸發過場（CG：四目相對）。旁白用原文第 3 段，接「沒有任何對白。」
3. 任務提示「到八百公尺起跑線」。站上起跑格觸發起跑事件：
   - 旁白：「但程徹那天在起跑線上蹲下時……」
   - 裁判：「各就位。」
   - 轉盤（`look:"wheel"`）題目「心裡在想什麼？」，選項「我要贏」「配速」「等跑完，我要去認識她」。選前兩項 → 旁白「腦袋裡沒有秒數、沒有配速」，轉盤重來且少掉選過的項目；選第三項才往下。
   - 裁判：「預備——」。之後約 2.5 秒是**偷跑判定窗**：起跑格四周放隱形觸碰事件，只在 `phase=set` 時有效。玩家一移動就踩到 → 哨音、畫面閃紅、裁判「偷跑。回到起跑線。」→ 把玩家移回起跑格，從「各就位」重來（轉盤不再出現）。
   - 判定窗結束 → 槍響 → 旁白「他的起跑，比發令槍早了整整兩個心跳。」
4. 比賽本身是自動演出（移動路線＋鏡頭），不需操作。衝線後鏡頭移到看台上抱著外套喝水的林向晚（CG：衝線望向看台），旁白用原文「那場比賽他拿了小組第一……」。
5. 任務提示「去體育館後門的販賣機」。林向晚在販賣機前，零錢掉在地上（CG：販賣機前）。調查零錢 → 拿到「十塊錢」→ 程徹：「妳的十塊錢。」→ 交給她 → 進中章。

### 中章（文字卡）
原文「後來他們真的在一起了。」到「程徹愣住了。」，停在「你以為那是巧合？」（CG：防波堤）。最後接一行旁白提示換人，例如「那一天，從她那邊看起來，是這樣的。」（新寫，作者定稿）。

### 第二輪：林向晚，同一天、更早的時間
同一張地圖，事件用頁面條件 `round=2` 換成另一套人物和對話。
1. 開場：她剛跑完四百。任務提示「去看台後面」。
2. 看台後面可以看到程徹在熱身。看台邊緣放隱形觸碰事件（`phase=watch` 時有效）：走出遮蔽 → 程徹頭上跳驚嘆號 → 「差點被看到。」→ 把她移回看台後。這段的限制是「不能被發現」。
3. 找他的隊友聊天，問出「他比完都會去體育館後門那台販賣機買水」，拿到線索。之後才解鎖下一個任務提示。
4. 看他的比賽：這次從看台的角度，看見他衝線後望向自己（同一張 CG 或反拍）。
5. 任務提示「去體育館後門的販賣機」。到了以後先買寶礦力（道具「寶礦力」），再出現分支選項：
   - 「讓零錢掉下去」→ `ending=A`
   - 「轉身離開」→ `ending=B`

### 結局 A
防波堤後半（文字卡）：原文「那天我早就在看台後面看到你在熱身了。」到「整座城市其實早就已經浸透了。」
接台北廚房小地圖：雨夜、窗上的霧氣。玩家操作程徹，走到林向晚身後觸發事件，對話照原文「向晚。」到「好啊。」；接原文最後三段。
最後拿到道具「備用鑰匙」，說明文字「把自己的門，交給另一個人。」（新寫，作者定稿）。結束畫面。

### 結局 B
文字卡（新寫，我依作者文風擬草稿，作者改到滿意為止）：她沒有繞過去，程徹一個人在販賣機前買水，兩人從來沒有說上話；扣回「自由是沒有人替你喊開始」。
結束畫面提供「回到販賣機前」，回到分支前重選。

## 4. 狀態（變數）

| 變數 | 值 | 用途 |
|---|---|---|
| `round` | 1 / 2 | 田徑場地圖的事件頁面切換 |
| `phase` | 各階段名稱（例 `bib`、`start`、`set`、`race`、`vending`、`watch`、`clue`） | 任務提示與判定窗開關 |
| `ending` | `""` / `A` / `B` | 分支 |

道具：號碼布、別針、十塊錢、寶礦力、隊友的線索（可做成道具或變數）、備用鑰匙。

## 5. 地圖

| 地圖 | 尺寸（暫定） | 內容 |
|---|---|---|
| 田徑場 | 約 40×30 格，`camera:"normal"` | 紅色跑道（含八百起跑線、終點線）、檢錄處帳篷、看台與看台後方通道、體育館後門與販賣機 |
| 台北廚房 | 約 12×9 格 | 小公寓廚房、雨夜窗、湯鍋 |

做法：每張地圖一張水彩俯視底圖（`settings.picture`），另放一層隱藏的碰撞層畫牆和障礙。

## 6. 美術清單

全部柔和水彩，先定一張畫風錨（風格參考圖），之後所有生成都帶這張。

- 地圖底圖 2 張：田徑場、台北廚房
- 走路圖（每人 3 格 × 4 方向）：程徹（高中）、林向晚（高中）、隊友、裁判、路人選手 1～2 種；結局 A 的成年兩人可以另做，或沿用高中版換衣服
- 立繪（透明底）：程徹、林向晚各有高中版和成年版，表情各 3～4 種
- CG 約 5 張：四目相對、衝線望向看台、販賣機前、防波堤、廚房擁抱

生圖只走既定工具（本機 codex、Larch、.11 codex-image）。去背走 cutout 流程。走路圖最難保持一致：如果兩位主角的走路圖始終產不穩，先回報作者，由作者決定是否暫時退回內建圖，不自行替換。

## 7. 驗收

每條路徑都在 Larch 播放器實際走過一次，手機和桌機各一次：

- 第一輪：漏拿號碼布直接走去起跑線 → 提示不會卡死；轉盤三個選項都選過；判定窗內移動 → 偷跑重來，可以重複多次；判定窗內不動 → 正常起跑
- 第二輪：走出看台被發現 → 拉回，可以重複；沒找隊友直接去販賣機 → 提示引導，不會卡死
- 結局 A、結局 B 都走到底；結局 B 的「回到販賣機前」能接上結局 A
- 存檔與讀檔：在每一輪中途存檔，讀回來狀態正確
- 總時長量一次，目標 8～10 分鐘

## 8. 技術上要先驗證的事（開工第一步）

1. **偷跑判定窗**：`parallel` 事件等待約 2.5 秒的期間，玩家能不能自由移動，隱形觸碰事件能不能中斷它並重置。這是整部作品的核心玩法，先在沙盒專案做最小原型。
2. **水彩底圖搭隱藏碰撞層**：picture 底圖對齊格子的實際效果。
3. **自製走路圖**：先產一位主角的 3×4 圖，在地圖上實際走動確認不跳格、不變臉。

三項都通過才開始量產素材；有一項不通過就回頭改設計並告知作者。

### 驗證結果（2026-10-05，本機 larch-preview，官方《雲之王國 RPG》王宮地圖改的拋棄式原型）

1. 偷跑判定：**通過**。做法：「預備」最後一步設 `phase=set`；`gun` 為 parallel 事件（條件 `phase=set`）：`wait 2500` → 槍響 → … → 最後才設 `phase=go`；起跑格四周放 touch 陷阱（條件 `phase=set`），第一步設 `phase=foul`。實測：預備後 0.3 秒移動 → 偷跑、主角送回，之後 3 秒以上槍沒響（平行事件每步前重查條件，被取消）；重來後不動 → 約 4 秒內槍響（平行事件可重跑）。轉盤 `look:"wheel"` 可用；`move` 自動移動與 `camera` 可用。
2. 圖片底圖＋隱藏碰撞層：官方王宮地圖就是這個做法（`picture` ＋ `visible:false, collision:true` 圖層），原型裡主角確實被擋住。
3. 自製走路圖、換主角（`kind:"hero"`）、立繪對話：《仙泉·香布纏．無雙》已做過，見 `~/xianquan-musou/docs/engine-notes.md`。第二輪換成林向晚用 `hero` 步驟。

順帶確認的格式規則：每個事件都要有 `sprite`（隱形事件用 `url:""`、32×32、1 格）；`screen` 參數要包在 `screen:{…}` 裡；`guidance` 不可為 null，用 `[]`。

## 9. 不做的事

- 戰鬥、多人連線
- 原文以外的新劇情（結局 B 與上面列出的少量新寫除外）
- 語音配音（時間有剩再評估）
