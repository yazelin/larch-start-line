# 《起跑總在開始前》設計規格

日期：2026-10-05（同日改版：加入四組自製功能與第二輪平台驗證）
用途：Larch 第三屆創作者挑戰《自由與限制》投稿作品
截稿：2026-10-24（評審週 10/25–10/31 仍可修 bug，以截稿前最後一版計分）

## 1. 目標與限制

- 作品長度 8～10 分鐘，使用 RPG 擴充功能（地圖探索、事件、道具、任務提示），再加上自製插件，讓玩法不受平台原生功能限制。作者要求「自製越豐富越好」。
- 劇情以 `canon/原文.md` 為準，原文不改字。新寫的文字（結局 B、備用鑰匙說明、轉盤選項、訊息草稿、路人台詞）放 `canon/新寫.md`，由作者定稿。
- 不打怪：所有地圖 `combat:"none"`。
- 美術全部自製，不用 Kenney 素材；畫風統一為柔和水彩插畫。
- 每一條路徑都要能走到結局，不能因為走錯或小遊戲失敗而卡死（挑戰規則）。

## 2. 主題怎麼對上「自由與限制」

| 挑戰頁的鎖 | 在作品裡的位置 | 玩家實際碰到的事 |
|---|---|---|
| 看得見的束縛 | 第一輪，起跑前兩秒 | 第一人稱起跑：槍響前一動就是偷跑，裁判吹哨重來；同時心裡想什麼由玩家自選 |
| 看不見的束縛 | 第二輪前半 | 林向晚不能被他發現、不能太刻意：要躲在看台後、要先算好他的時間 |
| 心裡的束縛 | 第二輪結尾的分支 | 販賣機前沒有任何東西擋她，只剩自己決定讓零錢掉下去或轉身 |

作品的回答：跑道上有人替你開槍，愛情沒有。自由是沒有人替你喊開始，所以槍得自己扣。結局 B 是這句話的反面（完全自由，卻從未起跑）。結局 A 的備用鑰匙是另一面：自己選來交給別人的限制。

心跳 HUD 是貫穿全作的線：開頭的「心臟撞擊胸膛」、起跑的「早了整整兩個心跳」、結尾的「平穩卻堅定的心跳」。

## 3. 遊戲流程

```
序章（文字卡）
 └ 第一輪：程徹（田徑場地圖，round=1）
    ├ ［起跑卡］第一人稱起跑・偷跑判定
    ├ ［配速卡］八百公尺節奏
    └ 回地圖 → 販賣機
       └ 中章（文字卡＋［草稿卡］訊息刪改三次）
          └ 第二輪：林向晚（同一張田徑場地圖，round=2）
             ├ ［筆記卡］推算他的時間
             └ 販賣機前分支
                ├ 讓零錢掉下去 → ［零錢卡］抓時機 → 防波堤後半（文字卡）→ 結局 A：台北廚房（小地圖）
                └ 轉身離開   → 結局 B（文字卡）→ 可回到販賣機前重選
```

［］是自製插件卡，由地圖事件 `jump` 過去，卡片結束後連線回到地圖卡（主角留在原格，已驗證）。

### 序章（文字卡）
原文第 1–2 段（「在槍響之前……」「所謂的起跑……」）。心跳 HUD 第一次出現。

### 第一輪：程徹，高二市運會選拔賽
1. 任務提示「去檢錄處拿號碼布」。拿到道具「號碼布」「別針」。
2. 經過終點線後方觸發過場（CG：四目相對）。旁白用原文第 3 段，接「沒有任何對白。」心跳上升。
3. 任務提示「到八百公尺起跑線」。站上起跑格 → 跳**起跑卡**（見 §5.2）。
4. 起跑卡結束 → **配速卡**（見 §5.3）。
5. 回到地圖終點線。鏡頭越過人群，移到看台上抱著外套喝水的林向晚（CG：衝線望向看台），旁白用原文「那場比賽他拿了小組第一……」。
6. 任務提示「去體育館後門的販賣機」。林向晚在販賣機前，零錢掉在地上（CG：販賣機前）。調查零錢 → 拿到「十塊錢」→ 程徹：「妳的十塊錢。」→ 交給她 → 中章。

### 中章
原文「後來他們真的在一起了。」與「人們總以為愛情的開始……」兩段。接著跳**草稿卡**（見 §5.5），對應原文「傳訊息時字斟句酌刪改的三次草稿」。之後是花蓮防波堤（CG：防波堤），原文到「程徹愣住了。」，停在「你以為那是巧合？」。最後一行換人提示（新寫，例如「那一天，從她那邊看起來，是這樣的。」）。

### 第二輪：林向晚，同一天、更早的時間
同一張地圖，事件用頁面條件 `round=2` 換成另一套人物和對話；主角用 `hero` 步驟換成林向晚。
1. 開場：她剛跑完四百。任務提示「去看台後面」。
2. 看台後面可以看到程徹在熱身。看台邊緣放隱形觸碰事件（`phase=watch` 時有效）：走出遮蔽 → 程徹頭上跳驚嘆號、心跳飆高 → 「差點被看到。」→ 把她移回看台後。
3. 蒐集線索（地圖上調查與對話）：秩序冊上他那組的開跑時間、隊友說「他比完都會去體育館後門那台販賣機買水」、她自己從看台走到販賣機要多久。
4. 蒐集完跳**筆記卡**（見 §5.4）推算時間。
5. 看他的比賽：從看台的角度，看見他衝線後望向自己。
6. 任務提示「去體育館後門的販賣機」。到了以後先買寶礦力（道具「寶礦力」），再出現分支選項：
   - 「讓零錢掉下去」→ **零錢卡**（見 §5.6）→ `ending=A`
   - 「轉身離開」→ `ending=B`

### 結局 A
防波堤後半（文字卡）：原文「那天我早就在看台後面看到你在熱身了。」到「整座城市其實早就已經浸透了。」
接台北廚房小地圖：雨夜（`environment.weather:"rain"`）、窗上霧氣。玩家操作程徹，走到林向晚身後觸發事件，對話照原文「向晚。」到「好啊。」；心跳 HUD 變成平穩；接原文最後三段。
最後拿到道具「備用鑰匙」，說明文字「把自己的門，交給另一個人。」（新寫，作者定稿）。結束畫面。

### 結局 B
文字卡（新寫，依作者文風擬草稿，作者改到滿意為止）：她沒有繞過去，程徹一個人在販賣機前買水，兩人從來沒有說上話；扣回「自由是沒有人替你喊開始」。
結束畫面提供「回到販賣機前」，回到分支前重選。

## 4. 狀態（變數）

| 變數 | 值 | 用途 |
|---|---|---|
| `round` | 1 / 2 | 田徑場地圖的事件頁面切換 |
| `phase` | 各階段名稱（例 `bib`、`start`、`race`、`vending`、`watch`、`clue`、`calc`） | 任務提示與事件開關 |
| `bpm` | 數字 | 心跳 HUD 讀的值；地圖事件與插件卡都會寫 |
| `fouls` | 數字 | 起跑卡寫回的偷跑次數（之後可用在旁白） |
| `clue_*` | true / false | 第二輪三條線索 |
| `calc_ok` | true / false | 筆記卡結果 |
| `coin_ok` | true / false | 零錢卡結果 |
| `ending` | `""` / `A` / `B` | 分支 |

道具：號碼布、別針、十塊錢、寶礦力、備用鑰匙。

## 5. 自製插件

一個私人插件 `start-line`（只用在這部作品），內含 1 個 HUD 與 5 張卡。插件卡都要能在手機上操作（觸控＋鍵盤）、深淺色都看得清楚、失敗可重來、一定送出 `larch:complete`。卡片寫入的變數全部列在卡片的 `pluginWriteVars`，讀的列在 `pluginReadVars`（少列會被靜默丟掉）。美術（背景、眼神、走路圖）以網址放在卡片的 `pluginValues`（`bg`、`eyesImg`、`him`），由 push.py 換成上傳後的網址，不寫死在 HTML 裡。

### 5.1 心跳 HUD（`heart`）
- 右上角，讀 `bpm`，畫一顆水彩風的心依 `bpm` 搏動，旁邊顯示數字。
- `bpm` 為 0 時隱藏（用 `visibleVariable` 或讀值自行隱藏）。
- 不攔截操作（`interactive:false`）。

### 5.2 起跑卡（`start-gun`，全螢幕）
- 第一人稱：指尖貼在紅色跑道上，低頭看白線。
- 「各就位。」→ 心裡想什麼的選擇（「我要贏」「配速」「等跑完，我要去認識她」，前兩項選了會散掉，原文「腦袋裡沒有秒數、沒有配速」）→「預備——」→ 心跳逐拍加速，槍在隨機 1.5～3 秒後響。
- 槍響前按下 → 偷跑：哨音、畫面閃紅、「偷跑。回到起跑線。」，`fouls+1`，重來（不再問想法）。
- 撐過去 → 槍響 → 旁白「他的起跑，比發令槍早了整整兩個心跳。」→ 寫 `bpm`、`fouls`，complete。

### 5.3 配速卡（`pace`，全螢幕）
- 八百公尺兩圈。畫面有節拍，玩家照節拍按鍵維持配速。
- 途中她抬頭的眼神會浮上來，節拍被打亂（原文「腦袋裡沒有秒數、沒有配速」）；最後直線變成衝刺連打。
- 不論表現都拿到小組第一（原文寫定），表現只影響卡片內的回饋文字。

### 5.4 筆記卡（`notebook`，全螢幕）
- 林向晚的筆記本，已蒐集的三條線索會寫在頁面上（讀 `clue_*`）。
- 玩家推算「要幾點幾分站在販賣機前」，用撥時鐘或選時間的方式作答。
- 答錯：筆記上畫掉，給一句提示，可重來；答對寫 `calc_ok=true`，旁白「我算了你的時間。」

### 5.5 草稿卡（`drafts`，全螢幕或嵌入）
- 一支手機的訊息輸入框。玩家挑一句想傳的話送出，手指停住、文字被一個字一個字刪掉，重來，共三次；第四次送出最簡單的那一句。
- 草稿內容是新寫文字，作者定稿。可參考作者的「格莉奇-AI對話手機」插件外觀，但這張卡不用 AI。

### 5.6 零錢卡（`coin-drop`，全螢幕）
- 販賣機前，她手裡的零錢。畫面一側是體育館轉角，他會在某個時間點轉進來。
- 玩家要在他看得到、又不會太刻意的那一刻鬆手（時機條）。太早：零錢掉了他還沒來，自己撿起來重來；太晚：他已經走到面前，重來。
- 成功寫 `coin_ok=true`，complete。

## 6. 地圖

| 地圖 | 尺寸（暫定） | 內容 |
|---|---|---|
| 田徑場 | 約 40×30 格，`camera:"normal"` | 紅色跑道（含八百起跑線、終點線）、檢錄處帳篷、看台與看台後方通道、秩序冊公告欄、體育館後門與販賣機 |
| 台北廚房 | 約 12×9 格 | 小公寓廚房、雨夜窗、湯鍋 |

做法：每張地圖一張水彩俯視底圖（`settings.picture`），另放一層隱藏的碰撞層畫牆和障礙。天氣與光影用 `environment`（田徑場午後光、防波堤傍晚與星、台北雨）。

- 走路圖（每人 3 格 × 4 方向）：程徹（高中）、林向晚（高中）、隊友、裁判、路人選手 1～2 種；結局 A 的成年兩人另做或沿用高中版換衣服
- 立繪（透明底）：程徹、林向晚高中版與成年版，表情各 3～4 種
- CG 約 5 張：四目相對、衝線望向看台、販賣機前、防波堤、廚房擁抱
- 插件卡用圖：起跑卡（指尖與白線的第一人稱）、配速卡（跑道背景、她的眼神）、筆記本頁面、手機外框、販賣機前的零錢特寫
- 心跳 HUD 的心形

生圖只走既定工具（本機 codex、Larch、.11 codex-image）。去背走 cutout 流程。走路圖如果始終產不穩，先回報作者再決定，不自行替換。

## 8. 驗收

每條路徑都在播放器實際走過一次，手機和桌機各一次：

- 第一輪：漏拿號碼布直接走去起跑線 → 不卡死；起跑卡三個想法都選過；偷跑可以重複多次；配速卡表現好與差都能過
- 中章：草稿卡三次刪改後一定送出
- 第二輪：走出看台被發現 → 拉回可重複；線索沒蒐集齊直接去販賣機 → 提示引導；筆記卡答錯可重來
- 零錢卡太早、太晚都能重來；結局 A、B 都走到底；結局 B 的「回到販賣機前」能接上結局 A
- 心跳 HUD 在每個場景的數值符合設計，結局 A 是平穩的
- 存檔與讀檔：每一輪中途、插件卡前後存檔，讀回來狀態正確
- 總時長量一次，目標 8～10 分鐘

插件卡另外要有本機自動測試：每張卡的 `larch:set` 名稱逐一比對卡片的 write 名單（防靜默丟棄）。

## 9. 平台驗證結果（2026-10-05，本機 larch-preview，拋棄式原型）

原型用官方《雲之王國 RPG》（市集 b14a7e2e…）的王宮地圖改。

1. **地圖上的偷跑判定：通過。** parallel 事件 `gun`（條件 `phase=set`）`wait 2500` 後槍響；起跑格四周 touch 陷阱第一步設 `phase=foul`。預備後 0.3 秒移動 → 偷跑、送回，計時中的槍被取消；重來不動 → 槍響。現在起跑改由起跑卡負責，這個做法保留作為退路。
2. **轉盤** `look:"wheel"`、**自動移動** `move`、**鏡頭** `camera`：可用。
3. **圖片底圖＋隱藏碰撞層**：官方王宮地圖就是這個做法，主角確實被擋住。
4. **自製 HUD 疊在 RPG 地圖上：通過。** 放在 `settings.plugins[id].playback.huds`；地圖事件改 `bpm`，HUD 即時更新；進出插件卡 HUD 都保留。
5. **地圖 → 插件卡 → 地圖：通過。** 地圖事件 `jump` 到插件卡，卡片讀得到變數、`larch:set` 寫回的值回地圖立即生效，**主角回到原本的格子**，等這個結果的 condition 事件會觸發。插件卡在 `settings.plugins[id]` 要有 `{enabled:true}`，否則顯示「這個專案沒有導入這個擴充功能」。卡片 html 存在節點的 `pluginHtml`。
6. 自製走路圖、換主角（`kind:"hero"`）、立繪對話：《仙泉·香布纏．無雙》已做過，見 `~/xianquan-musou/docs/engine-notes.md`。

格式規則：每個事件都要有 `sprite`（隱形事件用 `url:""`、32×32、1 格）；`screen` 參數包在 `screen:{…}`；`guidance` 不可為 null，用 `[]`。回到觸發跳轉的那一格時 touch 事件不會馬上再觸發，但離開再踩回會，所以跳轉事件要設 `once` 或條件。

尚未驗證：插件卡進行中存檔、讀檔後的行為（實作時列入驗收）。

## 10. 不做的事

- 戰鬥、多人連線
- 原文以外的新劇情（結局 B 與上面列出的少量新寫除外）
- 語音配音（時間有剩再評估）
