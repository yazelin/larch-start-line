起跑線

1故事

同一個下午，跑兩次

高二那年的市運會選拔賽，程徹在八百公尺的起跑線上蹲下，腦袋裡只有剛才在終點線後面抬頭的那個女生。

很多年後，林向晚才告訴他：那天販賣機前掉在地上的十塊錢，是她算好的。

同一個下午，先以他的視角跑一次，再以她的視角走一次。槍響之前，有些事早就決定了。

3圖庫

那一個下午，和之後的幾年

4玩法與主題

跑道上有人替你開槍，
愛情沒有。

這次挑戰的主題是「自由與限制」。田徑場上的限制都看得見：起跑線、發令槍、裁判的哨子。走出跑道以後，沒有人會替你喊開始，所以扳機得自己扣。作品把這件事拆成三道鎖，一輪比一輪看不見。

第一輪・起跑前兩秒

看得見的束縛

槍響之前動一下就是偷跑，裁判吹哨，回到起跑線重來。

第二輪・看台後面

看不見的束縛

她不能被他發現，也不能太刻意：要躲在看台後面，先算好他的時間。

第二輪・販賣機前

心裡的束縛

沒有任何東西擋她。讓零錢掉下去，或轉身離開，只剩她自己決定。

每一張卡，都是原文裡的一句話

起跑卡

偷跑判定

第一人稱蹲在起跑線上，指尖貼著紅色跑道。「各就位」之後先選心裡在想什麼：我要贏、配速，或等跑完，我要去認識她。前兩個想法浮上來一下就散了，對應原文「腦袋裡沒有秒數、沒有配速」。

「預備」之後心跳一拍比一拍快，槍會在 1.5 到 3 秒之間的某一刻響。槍響前點一下畫面就是偷跑：畫面閃紅、哨音、「偷跑。回到起跑線。」偷跑幾次都可以重來。

配速卡

配速

八百公尺兩圈，照著每 650 毫秒一拍的節拍點畫面。跑到一半，她抬頭的眼神浮上來，節拍跟著亂掉；最後一百公尺變成衝刺。

原文寫定他拿了小組第一，所以怎麼跑都會過，跟得好不好只改變衝線時的那一句話。

草稿卡

刪改三次的草稿

原文說，在正式告白之前，有「傳訊息時字斟句酌刪改的三次草稿」。這張卡是一支手機：挑一句想傳的話，手指停住，文字一個字一個字被刪掉，再挑一次。刪滿三次，第四次才送得出去。

筆記卡

躲起來，再算好他的時間

第二輪換成林向晚。從看台後面走出遮蔽，他頭上會跳出驚嘆號，她的心跳飆高，被拉回看台後。

她要蒐集三條線索：秩序冊上他那組的開跑時間、隊友說他跑完會先做什麼、她自己從看台走到體育館後門要多久。最後在筆記本上填出幾點從看台出發，填錯會被畫掉並給一句提示，可以一直重算。

零錢卡

販賣機前的分岔

到了販賣機前，選項只有兩個：讓零錢掉下去，或轉身離開。

讓零錢掉下去，接著是一條時機條：他從體育館轉角走過來，指針走到中間那一段才鬆手。太早，零錢滾到腳邊他還沒看見；太晚，他已經走到面前。兩種都能重來。

心跳

從頭跟到尾的心跳

右上角一顆水彩的心，依數字搏動。地圖事件和每張卡都會改它：「預備」時每一拍往上加，差點被他發現時跳到 150，台北廚房那一夜降到 72。

原文開頭是「心臟撞擊胸膛」，結尾是「平穩卻堅定的心跳」，這顆心走的就是這段路。

結局 A

台北的冬夜

防波堤後半，接到台北下著細雨的小廚房。最後拿到一副備用鑰匙，說明只有一句：

「把自己的門，交給另一個人。」

結局 B

她沒有繞過去

程徹一個人在販賣機前買了水，回去收操。後來在別的比賽又遇過幾次，誰也沒有先開口。

「她一直很自由，自由到始終沒有起跑。」
